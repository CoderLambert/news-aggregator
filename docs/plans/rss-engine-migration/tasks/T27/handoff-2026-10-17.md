1. 在集成工作树先读本文件、[T27 报告](report.md)、[T18 报告](../T18/report.md) 与 `git status --short`；保留现有未提交改动。

3. RSSHub 公网链路等 `rsshub.news.lambert.host` 真正部署后再开始验收：有效公网 DNS/TLS、回流、固定发布者认证、Miniflux 拒绝重定向、凭据不进入 DTO/OPML/日志。具体门禁见 [T18 README](../../../../../ops/rss/T18/README.md)。
4. 保持 Miniflux `FETCHER_ALLOW_PRIVATE_NETWORKS=0`。不要把 `http://rsshub:1200` 或 `http://127.0.0.1:1200` 注册为 Feed；不要为通过测试而关闭 TLS 校验、打开私网访问或使用公共 RSSHub demo。
5. 真实用户数据、真实 AI/TTS provider、生产部署和 T26 双库恢复证据各有独立门禁；本地合成通过不能替代它们。
