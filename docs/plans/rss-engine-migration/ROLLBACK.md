# 回滚、暂停与灾难恢复

状态：待实现/未演练。878b690 尚不能作为已证明读取 available/新 ACL 的回滚目标。

## 工具、兼容基点与演练

T03 扩展现有 manifest/部署脚本的 RSS 角色、停写及两库备份恢复；不依赖文章 ACL 实现完成，不负责封存生产兼容基点。基线 rollback.sh 的 schema exact-match 和无条件 crawler 角色必须显式适配，不能假定 additive 就安全。

T26 吸收原 T36：选择含完整旧/新 fencing、available/ACL、译文版本读取的候选过渡镜像；在隔离副本完成迁移、切换、应用回滚和两库恢复。通过后封存实际 SHA/digest/schema/角色/配置及证据。候选可用于隔离测试，尚未封存不能用于生产；T29 试点前必须已有封存产物，无循环前置。

默认同 schema 兼容镜像最简单；领域 DDL 可以先于 UI 以小提交合入，最终封存必须覆盖计划发布的完整 schema。目录/已读/OPML 的后续 DDL 正常评审并在试点前重测目标兼容性，不全局禁止新增 DDL，不用 migration 子集充当测试。原应用回滚与灾难恢复是不同操作。

## 首选动作

| 故障 | 动作 | 数据限制 |
| --- | --- | --- |
| 引擎/API 不可用 | 暂停受影响操作，缓存继续读 | 不删正文/译文、不恢复隐蔽抓取 |
| 单源质量/政策变化 | owner paused/epoch 递增，取消过期操作，政策立即收紧 | publication 保持；共享 Feed 按有效引用处理 |
| 应用缺陷 | 关闭入口或回到封存兼容镜像 | 不 reverse migration、不恢复全库 |
| 来源切换失败 | 共享切换组保持 paused，verify 后恢复 | 旧支持源可按批准事故范围回 legacy，新 Feed 只能暂停 |
| 旧进程复活 | 停止扩大迁移，停对应入口并修复启动配置 | 保留当前数据；重启再次验证 |
| schema/实例不符 | 保持停写并核对目标 | 不猜数字身份、不自动重绑定 |
| 库损坏 | 单独确定恢复点/RPO并恢复配对备份 | 明确恢复点之后的数据损失 |

## 普通应用回滚

1. 核对故障范围、环境、当前版本、批准的目标 manifest 和兼容证据；没有受测目标先暂停。
2. 禁止新控制请求，暂停受影响来源/同步，递增来源和主写版本；排空或 fence 在途任务。应用切换时停全部 SQLite writer 并留一致性备份。
3. 启动受测兼容角色，保留新增 News、译文历史和用户关系；不恢复数据库，不无条件启旧 crawler。
4. 检查 available/旧内容、ACL、译文版本、来源 owner、共享绑定引用和进度；恢复旧采集须在批准的事故范围内。
5. 记录版本、数据不变量和结果；修复受影响路径并重跑相关验收，无关开发可继续。

切换方向往返都递增 epoch/body_owner_version。回滚后完成的旧任务也不能复活写入权；部署前已启动且没有令牌的旧二进制必须先排空/终止，不能靠新增 CAS 改造其内存状态。

## 灾难恢复

1. 核对配对备份、两个恢复点、版本/实例/映射 hash 与 RPO。停止 app、sync、legacy、indexer、channel-worker、后台线程及 Miniflux 写入。
2. 验证 SQLite snapshot/sidecar、PG dump、受保护 secret 备份，覆盖前留 prior backup；不复制活动 SQLite 主文件代替一致性快照。
3. 保持采集关闭恢复数据，校验 schema/身份/映射，启动兼容 app 只读检查，再开启 sync 对账和获批写入口。
4. 用户关系、正文/译文归档、权限和对账验证通过后恢复；引擎保留期外缺口不得声称能从 Feed 补齐。

复用现有部署权限/变更记录；一次批准可覆盖明确批次，不增加自定义审批文件协议。CLI 默认 dry-run、显式执行、目标校验及恢复覆盖保护保留。down -v、reverse migration、全库覆盖不属于普通回滚。

## 验收复用与删除时机

T03 测工具，T26 测真实组合并封存；使用同版本工件时不在独立“封存任务”重跑一遍。每源切换验证其 owner/引用/数据和覆盖差异，复用公共权限/恢复测试。旧栈完全删除后 T33 在最终镜像复验角色、恢复、重启和关键端到端，因为运行组成确实改变。

全部来源替代或明确停更、试点/批次通过且兼容镜像留存后，T30 停运行入口，T31 删代码/依赖。最终部署须处理上一版本残留容器/cron/systemd/override；仅删除仓库声明不算退出。
