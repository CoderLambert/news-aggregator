# 向量检索部署前检测与配置推荐

当前阶段：设计草案，待用户审阅；本设计中的硬件探测与推荐命令、自动配置和模型升级均尚未实现。

阅读：[完整方案](完整方案.md)。用户目标是部署前检测机器、解释推荐配置与部署方式，用户选择后才执行部署。检测不修改机器、不安装依赖、不下载模型、不切换索引。

本设计拟结合现有 CPU 部署与索引候选集合切换能力，并评估 GPU 独立实现。GPU 改动当前位于 `feat/gpu-embedding-20261021`；本机已验证的是现有应用使用的本地 CUDA 镜像衍生版本，尚无已进入主线的通用 GPU 镜像发布。实施时需核对分支是否已进入实际基线，不假定已合并。
