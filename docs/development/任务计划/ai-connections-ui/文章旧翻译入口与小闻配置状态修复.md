## 根因与实现

截图红条文字来自 backend/api/services/ai_execution.py 的 T01 过渡围栏，调用方为旧 NewsTranslateFullView。前端 NewsDetail 的正文工具栏和翻译后朗读仍调用 useTranslation 的旧接口；小闻已走个人模型问答，因此同页出现模型已配置与配置未完成的矛盾。

本轮复用 useDefaultAIModel 读取全局/全文翻译绑定。已有个人配置（含失效配置）、配置读取中或读取失败时，新翻译入口进入既有 PrivateTranslationPanel，直接读取已保存模型并显式确认发送；不降级为旧服务商或站点 Key。顶部翻译及其重试定位并聚焦该面板；翻译后朗读同样先进入面板确认，不偷偷发出旧版翻译。已保存在本账号/文章版本下的旧任务恢复仍保留，但禁止创建新的旧版任务。历史错误中的 T01 过渡文案在个人路径下不再当成当前配置状态。

小闻区分默认模型读取失败和确实未配置；读取失败提供重新读取，不误导去重新配置。有可用模型时仅展示名称，不保留模型设置链接；推荐问题名称与 ID 相同只展示一次。
