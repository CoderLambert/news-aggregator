# 新订阅自动整理与分组操作改进

按已批准的方案实现：高把握自动加入已有个人分组，拿不准的集中待确认；人工修改优先，自动整理可撤销。

[实施计划与接口合同](implementation.md)包含 AG-04.1、AG-05.1、AG-06.1、AG-07.1 的范围、依赖和检查要求。

当前状态：恢复实现已本地提交为 `d93beac118be31767097e251f6447edcc59be87c`。用户接受该提交对应预览后又指出新旧流程不够醒目；看板 #21 已将默认流程明确为“频道 → 建议的已有分组 → 匹配依据 → 调整并确认”，并区分待确认与未匹配状态，旧 topics 保留为明确标记的次要入口。变更后候选已完成定向测试和 9531 合成浏览器验收，待用户重新体验确认。详见[本地交付记录](local-acceptance-20261023.md)。未获明确请求不推送、不建 PR、不启动 CI。

验收时重点查看：

1. 首页三个固定阅读范围与可搜索分组；切换到全部订阅搜索后保留搜索词。
2. 分组管理批量加入、移动、移出，移出不取消订阅。
3. 智能整理默认展示已有分组四步主流程；建议卡片分别显示状态、建议的已有分组和匹配依据，未匹配频道可保持未分组或手动调整。
4. 新订阅资料不足时等待，补齐资料后自动继续；手动移出的频道不会自动加回。
5. 自动整理历史可撤销，后续人工操作保留。

后台 AI 需用户另行明确开启并绑定本人模型，初期 AI 结果均需确认。离线测试与合成数据预览只支撑本地候选验收；不代表真实模型、生产、部署或线上回滚通过。
