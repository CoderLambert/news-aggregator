验收时重点查看：

1. 首页三个固定阅读范围与可搜索分组；切换到全部订阅搜索后保留搜索词。
2. 分组管理批量加入、移动、移出，移出不取消订阅。
3. 智能整理默认展示已有分组四步主流程；建议卡片分别显示状态、建议的已有分组和匹配依据，未匹配频道可保持未分组或手动调整。
4. 新订阅资料不足时等待，补齐资料后自动继续；手动移出的频道不会自动加回。
5. 自动整理历史可撤销，后续人工操作保留。
