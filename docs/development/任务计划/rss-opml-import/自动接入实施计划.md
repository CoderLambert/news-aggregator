# OPML 自动接入实施计划

> 执行方式：使用 superpowers:executing-plans，在当前隔离工作区按步骤完成。用户已明确要求开始实现，无需重复等待计划确认。

目标：实现已批准的自动接入、公平调度与去重设计。
架构：保留单协调进程与 SQLite 短事务；个人 FeedOperation 通过 shared_operation 指向现有系统收敛操作。网络槽有界并行，完成后按个人意向分别落地。
技术栈：Django/SQLite WAL、Python ThreadPoolExecutor、React/TanStack Query。
设计：[自动接入调度设计](自动接入调度设计.md)。基线 101ea60e0bfc6d631f20cb653cd45bf8a6f78592。

约束：沿用 Miniflux；不复制环境/数据库，不部署迁移，不推送；依用户要求不运行测试、lint、类型检查或 CI。源码人工核对和提交 diff 检查不能称为运行验证。

重点：并发重复创建、跨用户取消、移除后迟到落地、未知结果重发、已订阅项错误计额度；分别纳入下面步骤的代码审阅与验收记录，自动化回归执行均 NOT_RUN。

- [x] 1. 数据与订阅去重：models.py/import_models.py、0083 前向迁移、subscriptions.py、subscription_work.py。接口 attach_subscription_work(operation) 与 finish_subscription_work(operation)，个人操作保留 actor；系统物理操作共享。安全复用 ready 来源和已有订阅不占网络槽，quota 在去重后检查。数据库约束和 SQLite 写锁兜底。
- [x] 2. OPML 调度与状态：opml.py/import_scheduler.py、opml_views.py。每用户轮转准入、逐项 next_attempt，移除旧批次冷却。重查去重，记录 outcome 与 duplicate_count；批次暂停/继续/取消剩余只影响自己的意向，移除继续遵守 created_subscription 来源。
- [x] 3. 控制槽、公平性及恢复：control_worker.py/control_scheduler.py、operations.py、runtime.py、additions.py。4 个新增槽、1 个恢复槽、每用户竞争时 2 个、每站点 1 个；排除个人跟随操作的物理领取，保留 binding/lease/policy fencing。接入调度与同步独立，每秒检查并完成后补位；外部退避与24小时恢复窗口持久化，未知只核对并限制积压。
- [x] 4. 前端进度：opmlTypes.ts、OpmlDialog.tsx、OpmlHistory.tsx。兼容 status，展示 outcome/reason/next_attempt 和重复计数；预览默认排除已订阅项；展示自动恢复及批次暂停/继续/取消操作，按用户隔离缓存。
- [x] 5. 人工通读全差异与取消/共享调用链，记录实现范围和 NOT_RUN；按 newshub-stage-commit 使用唯一 Luna 委托完成本地提交。最终独立代码审阅仅看源码，不运行检测；修复实际发现的问题，完成后再经同一交付规则提交。

本阶段跨越共享 schema 与订阅协议，由一个实现者串行写入；不拆出不可运行的中间产品提交。任务5之前不声称通过运行验收。

## 实施记录

- 裁定：用户的明确“不检测”覆盖技能的 TDD/测试执行要求，本轮不运行自动化测试，也不以静态检查替代测试通过。
- 裁定：共享物理工作复用现有 reconcile_binding 产生的系统操作；不同用户/批次保留独立个人意向，避免首个导入者取消整项共享任务。

- 实现完成后的源码审阅发现5条具体失败路径，已修正：未知创建核对 GET 失败时保持 unknown fence；添加记录禁止绕过 OPML 批次的独立重试；管理员物理历史排除个人 follower；manual_blocked 的有效个人意向可随核对成功恢复；settlement 在 SQL 筛有效意向后再限额。
- 裁定：新增 shared root 的结果落地每事务最多20个个人意向，余下由独立 settlement 继续，避免一个热门来源拉长单次 SQLite 写锁。
- 裁定：添加记录中的 OPML 重试入口明确拒绝并引导导入历史，保留该批次完整取消/移除语义；普通手动新增入口不变。
- 裁定：管理员源核验、引擎重启证据和推荐冷却查询仅统计真实物理操作；个人 follower 不属于共享引擎的请求历史。
- 回归用例已补充，测试、构建、lint、类型检查、压力测试、CI、真实浏览器和运行迁移全部 NOT_RUN。源码审阅不等同运行验证。
