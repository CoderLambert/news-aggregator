# RSSHub 地址接入与首页订阅衔接

用户已审核统一站点 RSSHub 的方案，并要求同时修改首页刷新与分类设置。沿用已有隔离工作区和未提交实现；本轮本地交付，不合并、推送或部署生产。

用户输入 rsshub://twitter/user/elonmusk 后直接进入 Feed 连接流程。服务器使用单一管理员配置的 HTTPS RSSHub 网关，复用 routes 参数白名单、Miniflux Worker、现有未知结果对账。别名与对应网关 HTTPS URL 规范化为同一 FeedBinding；保存可读别名与配置版本，不能因更改网关而默默重绑定。个人添加、管理员新增、推荐地址更正及 OPML 使用统一解析。未配置、未验证、未开放路由或缺少所需能力时给出明确中文错误，不请求任意服务器，不依赖公共演示实例。

配置包括 enabled/origin/version/批准路由/已验证能力；默认关闭。执行批准同时涵盖公开 DNS/TLS/回流及网关阻止重定向、认证隔离。Twitter 仅开放公开信息；真实 Twitter 所需认证和公开性必须单独验证，不将合成证明当作真实可用。网关专用 Basic Auth 仅由 Worker 从固定文件引用读取并交给 Miniflux，不写 URL、操作输入/输出、浏览器、日志或 OPML。不得放宽私网或自动改用第三方付费服务。仅消费 Feed，不额外抓取 Twitter 正文。

个人频道分类保存于当前用户的 ChannelSubscription，可在添加时选择、频道详情修改；与多选分组独立。分类参与当前用户首页筛选，映射共享 Feed 历史及后续文章，不改共享 News 分类/正文或其他用户偏好。默认未选时沿用原文章分类。新增订阅在后台成功时提交分类，取消/迟到响应不得提交。

添加接受、后台成功/失败、取消、修改分类和公开发布后均按 viewer 刷新频道目录、个人订阅、首页来源和文章查询。未知/连接中不展示假订阅；添加记录在成功后刷新一次，不每轮轮询清空首页。查询与异步结果在账号切换后失效。

验收：别名/HTTPS 去重、非法参数/私网/跨源拒绝、未配置明确失败、配置变化围栏、认证不出现在 DTO/OPML、个人分类隔离和历史筛选、成功后来源刷新与迟到响应、现有 RSS 回归。使用隔离数据库/合成引擎及浏览器；真实 RSSHub/Twitter 分别记录 PASS 或 BLOCKED。保留真实账号、订阅、文章及现有采集下界。
