# AG-07 后台分类状态与停止操作

基线 main `bbb671d`。复用现有管理员配置与 job/lease，不新增监控平台或后台队列。

- 管理员 GET 只读返回 runtime：授权/全站开关就绪、当日入队预算、queued/running/failed/cancelled 数量、过期租约、已派发失败与下一次等待时间；刷新不调用 Provider，不宣称 worker 已在线。
- 停用、更换授权 owner/模型或降低预算时，同事务取消未完成的全站任务并清空旧 token/lease。现有 worker guard/CAS 阻止迟到结果写入；在途请求可能仍计费，页面明确提示。私人提案和已完成主题/分组保留。
- 后台重新允许分类后，仅有当前授权快照且确定未派发的 cancelled/failed 记录可以新建受日预算限制的任务；已派发/旧未知记录不能自动重发。新任务保留历史取消记录并以当前创建时间计入当日预算。
- 原 AG-05 的 429/Retry-After 有界退避、5xx/超时无自动重发和原 AG-06 的 owner 预算隔离继续有效。

验证：typecheck、管理员只读状态/显式停用组件场景 1 PASS、生产 build PASS；Python AST/diff 及 runtime 无写操作结构核对 PASS。新增 owner/global 私有隔离停用 DB 回归保留，但数据库测试 NOT_RUN（pytest/PyYAML 缺失）。真实 Provider、实际后台进程、生产迁移/部署和人工浏览器 UAT NOT_RUN。

无新增迁移、真实凭据、生产进程或主机设置修改。本轮按用户授权集中 CI。回退代码可移除状态/停止增强，不删除现有数据；正式上线仍需原 AG-07 发布验收。
