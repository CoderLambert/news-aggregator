## 本次交付的完整功能

超过一次输出上下文预算的 Markdown 长文，也能安全分块、连续展示进度，并生成没有缺段的完整译文。

**允许修改范围**：复用 T05 任务/快照/结果，在单功能内补内容预算、Markdown 保护分块、逐块完成校验、最终合并。

**本次明确不做**：不搞通用文档编译系统、不引入新的队列和模型回退，不把截断当成功。

### 可直接复现的验收路径

长文含代码、Markdown标题/链接/表格→显示多段进度→合并无丢段→刷新同结果。
