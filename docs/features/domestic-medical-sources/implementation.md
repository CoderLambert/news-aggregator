## 关键兼容性

- `CrawlerTarget.spider_name` 继续保存 `source_key`，既有运行历史和 API 字段不变。
- 代码来源显示为“代码维护”，动态来源显示为“后台维护”。
- Feed 状态以 `source_key + endpoint URL + config version` 隔离。
- 已排队任务使用创建时快照；后台修改只影响新任务。
- 重新探测会撤销审批并立即关闭调度，无论新探测结果成功与否。
