# 正文查看权限

权限：`api.view_article_body`（可查看正文并按需请求获取）。启用中的超级管理员默认具备；之后可以通过 Django 管理后台的用户权限或用户组授予其他账号，不需要给账号管理员身份。

该权限放开原先仅摘要频道的站内正文显示和按需获取。已有有效正文直接返回，不重新排队；没有权限的账号沿用原有频道策略。前端只使用服务端返回的 `body_access_granted`、`can_fetch_full_content`，不能通过请求参数自授权限。

按需请求记录请求者，worker 执行、持久化前再次检查权限；重复请求复用任务。来源明确停采、未登记域名、私网和非法链接、摘要或产品类型、真实性校验、限流、重试上限及站点只读模式继续生效。权限不保证来源能返回正文，不绕过付费墙。

发布需要先备份数据库，运行迁移 `0044_article_body_access`，更新前后端并重启服务和正文抓取 worker。仅启动 `channel_worker` 不会执行正文抓取任务。全站自动抓取不是本功能的前提。
