# 个人频道与资讯流 UI 改版（2026-10-13）

## 版本与边界

- 基线：`main@4eea5814cef56e2f79f6d771fbd035e3424f0a53`。
- 页面：`/`、`/channels`；沿用既有频道 API、订阅/多分组模型、新闻范围 URL 参数与历史导航。
- 本次目标是减少操作干扰和首屏非内容高度。**不修改来源采集策略、正文获取、数据库或权限判断。**

## 审核发现与对应修改

| 现状 | 影响 | 处理 |
| --- | --- | --- |
| 资讯页阅读范围与地区分成两行 | 筛选区挤占文章首屏 | 合并为同一范围工具条，保留移动端范围下拉与地区按钮 |
| 搜索、筛选条件与两个清除入口叠加 | 不易判断清除范围 | 搜索与高级条件统一容器；“清除分类与来源”只影响这两种条件；跨搜索/地区的“清除全部条件”保留原全量重置 |
| 频道页三个视图和过滤表单平铺 | 管理入口与内容混杂 | 桌面侧栏导航，移动端横向可换行视图按钮 |
| 二列等宽频道卡片包含说明、操作与全量分组复选框 | 信息密度低，浏览路径长 | 改单列紧凑频道行；“管理分组”按需展开 |
| 批量管理默认占据一整行，即使未选择频道 | 主操作分散 | 提供“全选当前结果”，已选择时才出现批量操作区 |
| 语言/类型是常驻下拉 | 大多数用户无需使用 | 放入“更多筛选”，启用时保持可见，防止隐藏已生效的筛选 |

## 信息架构

### 最新资讯 `/`

1. 页标题：当前阅读范围概览与返回阅读目的。
2. 主导航：全部资讯 / 我的订阅 / 未分组 / 自定义分组；同一行提供国内/国际与管理频道。
3. 查找：关键词、搜索模式及分类/来源的渐进筛选。
4. 条件反馈：分类/来源支持独立清空；搜索和地区存在时提供“清除全部条件”。
5. 结果：先阅读标题与摘要，再进入详情。保留内容状态、医学内容提示、屏蔽及撤销。

### 频道管理 `/channels`

1. 顶部：频道管理与订阅数。
2. 导航：全部 / 已订阅 / 分组管理。
3. 查询：名称与地区常驻，语言和来源类型按需展开；显示结果数量和全选入口。
4. 频道行：名称、地区/语言/类型、文章量、说明、订阅操作，订阅后的分组可按需编辑。
5. 分组页：创建、切换、重命名、删除、批量添加/移除。删除分组保留订阅。

## 交互与不变量

- 阅读范围切换不丢失搜索/分类，清空临时来源并返回第一页；URL 优先于已保存偏好。
- 地区切换清空临时来源与分页；无效地区参数仍报错，不默认扩大为全部内容。
- “清除分类与来源”必须保留关键词、地区、阅读范围。
- “清除全部条件”清除搜索模式、关键词、来源、分类、地区，但保留个人阅读范围与分组。
- 同一频道可加入多个分组；单频道编辑和批量编辑使用原 API；取消订阅须二次确认受影响分组。
- 已停用、RSS 待验证的频道不能新订阅，已订阅者仍保留历史入口。
- 登录、只读模式与异常重试行为保持不变。
